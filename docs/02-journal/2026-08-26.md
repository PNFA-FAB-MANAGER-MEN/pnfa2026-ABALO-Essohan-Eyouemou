## 1. Bases de l’électronique dans un FabLab

### Ce que j’ai appris

- Découvrir les **bases de l’électronique** dans un environnement FabLab.
- Comprendre le rôle des principaux composants électroniques.
- Découvrir les notions de **tension, courant et résistance**.
- Comprendre le fonctionnement d’un **circuit électrique simple**.
- Identifier les différents composants utilisés dans les projets électroniques.

### Comment ça se fait

1. Identifier les différents composants électroniques.
2. Comprendre le rôle de chaque composant.
3. Réaliser un circuit électrique simple.
4. Relier correctement les composants entre eux.
5. Alimenter le circuit avec une source d’énergie.
6. Vérifier le fonctionnement du circuit.
7. Utiliser des outils de mesure lorsque cela est nécessaire.

### Quelques composants importants

- **LED** → produit de la lumière.
- **Résistance** → limite le courant électrique.
- **Bouton poussoir** → permet d’ouvrir ou de fermer un circuit.
- **Capteur** → permet de détecter une information provenant de l’environnement.
- **Microcontrôleur** → permet de programmer et contrôler un circuit électronique.
- **Alimentation** → fournit l’énergie nécessaire au fonctionnement du circuit.

### Principe de base

**Alimentation → Composants électroniques → Fonctionnement du circuit**

## 2. Fabrication additive — Des principes généraux à l’impression 3D FDM

### Ce que j’ai appris

- Comprendre le principe de la **fabrication additive**.
- Découvrir les différents principes de fabrication additive.
- Comprendre le fonctionnement de l’**impression 3D FDM**.
- Découvrir les principales étapes permettant de passer d’un modèle numérique à un objet physique.
- Comprendre le rôle du **filament** dans l’impression 3D.

### Comment ça se fait

La fabrication additive consiste à **ajouter progressivement de la matière** pour fabriquer un objet.

Pour l’impression 3D FDM :

**Modèle 3D → Slicer → G-code → Imprimante 3D → Objet imprimé**

1. Créer ou télécharger un **modèle 3D**.
2. Importer le modèle dans un logiciel de **slicing**.
3. Préparer et positionner le modèle.
4. Choisir le matériau, par exemple du **PLA**.
5. Régler les paramètres d’impression.
6. Découper virtuellement le modèle en différentes couches.
7. Générer le **G-code**.
8. Envoyer le fichier à l’imprimante 3D.
9. L’imprimante chauffe et fait fondre le filament.
10. La buse dépose la matière **couche par couche**.
11. Les couches s’empilent progressivement jusqu’à obtenir l’objet final.

### Principe du FDM

**Filament → Chauffage → Fusion → Dépôt couche par couche → Objet 3D**

- Réfléchir aux différentes technologies pouvant être utilisées.

Pour réaliser un projet FabLab :

1. Identifier un **problème ou un besoin**.
2. Définir l’objectif du projet.
3. Imaginer une solution.
4. Identifier les matériaux et les composants nécessaires.
5. Choisir les machines et technologies adaptées.
6. Concevoir un prototype.
7. Fabriquer le prototype.
8. Tester son fonctionnement.
9. Identifier les problèmes.
10. Améliorer le prototype.
11. Réaliser la version finale.

### Principe

**Idée → Conception → Prototype → Test → Amélioration → Réalisation finale**

## 4. Introduction à la découpe laser

### Ce que j’ai appris

- Découvrir le principe de la **découpe laser**.
- Comprendre la différence entre **gravure laser** et **découpe laser**.
- Découvrir les principales étapes de préparation d’un travail pour une machine laser.
- Installer le logiciel **xTool**.

### Installation de xTool

**Comment ça se fait :**

1. Télécharger le logiciel **xTool**.
2. Installer le logiciel sur l’ordinateur.
3. Ouvrir **xTool**.
4. Connecter ou sélectionner la machine laser.
5. Vérifier que la machine est correctement reconnue.
6. Découvrir l’interface et les différents outils disponibles.
7. Préparer un premier fichier pour la gravure ou la découpe.

### Principe de la découpe laser

Le laser utilise un **faisceau lumineux très concentré** pour chauffer la matière.

Selon les paramètres utilisés, le laser peut :

- **Graver** → retirer une petite quantité de matière pour créer un motif ou un texte.
- **Découper** → traverser complètement la matière pour séparer une pièce.

### Principe général

**Conception → Préparation dans xTool → Réglage des paramètres → Laser → Gravure/Découpe → Objet final**
