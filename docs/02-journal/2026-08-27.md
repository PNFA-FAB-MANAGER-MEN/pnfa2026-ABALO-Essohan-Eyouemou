## 3. Du modèle 3D au G-code

### Le rôle du slicer

**Ce que j’ai appris :**
- Comprendre le passage d’un **modèle 3D** à un objet imprimé.
- Comprendre le rôle du **slicer**.
- Découvrir le **G-code**.
- Installer **Bambu Studio**.
- Installer **PrusaSlicer**.

### Comment ça se fait

**Modèle 3D → Slicer → G-code → Imprimante 3D → Objet physique**

1. Créer ou télécharger un modèle 3D.
2. Le modèle est généralement enregistré au format **STL** ou **3MF**.
3. Importer le modèle dans **Bambu Studio** ou **PrusaSlicer**.
4. Positionner et orienter le modèle sur le plateau virtuel.
5. Sélectionner l’imprimante 3D.
6. Sélectionner le matériau utilisé.
7. Régler les paramètres d’impression :
   - **Hauteur de couche**
   - **Vitesse d’impression**
   - **Température**
   - **Remplissage (Infill)**
   - **Supports**
8. Lancer le **Slicing**.
9. Le slicer découpe virtuellement le modèle en plusieurs couches.
10. Le slicer génère ensuite le **G-code**.
11. Le G-code contient les instructions nécessaires au fonctionnement de l’imprimante.
12. Envoyer le G-code à l’imprimante 3D.
13. L’imprimante interprète les instructions et imprime l’objet **couche par couche**.

### Principe du G-code

Le **G-code** est un langage de commandes utilisé pour donner des instructions à une machine.

Il permet notamment de contrôler :
- les déplacements de la tête d’impression ;
- la vitesse ;
- la température ;
- l’extrusion du filament ;
- certaines fonctions de la machine.
